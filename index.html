TicketWave — AI-Powered Bot Detection

A real-time bot detection engine for ticket booking platforms, built on passive mouse behavioural analysis — no CAPTCHA, zero user friction. Browser signals are collected by an invisible JavaScript collector injected into the page, and a companion Chrome Extension provides live session monitoring that integrates into an existing production environment without access to source code — a demonstration of non-invasive security tooling deployment. The goal is detecting and blocking automated bots that book tickets faster than human users, protecting fair access on high-demand ticketing platforms.

Grew directly out of the abuse patterns I see on high-demand government booking systems.
